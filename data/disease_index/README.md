# Bundled disease index

The complete available 152,295-record retrieval snapshot is stored once, inside
the installable Python package:

- `../../medcase_agent/resources/disease_index/records.jsonl.gz`
- `../../medcase_agent/resources/disease_index/manifest.json`
- `../../medcase_agent/resources/disease_index/corrections.json`

See [the data and retrieval documentation](../../docs/disease_index.md) for
fields, source hashes, counts, exclusions, and re-export instructions. The index
contains disease names and public citation metadata, with no abstracts,
classification labels, patient records, or predefined benchmark splits.
